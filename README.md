# Agrah M V - Portfolio

A minimal, dark-first personal portfolio built to showcase backend engineering experience, operating principles, and technical arsenal. 

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Key Features
- **AG-01 Interactive Companion**: A reactive, state-driven AI desktop companion built with Framer Motion that tracks cursor movement, scroll velocity, and features autonomous emotional states.
- **Scroll Animations**: Smooth viewport-triggered fade-in animations for a premium reading experience.
- **Nothing OS Aesthetic**: Minimalist, dark-first design with a signature orange accent and terminal-style typography.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Structure
- `data/profile.ts`: Centralized content for experience, projects, skills, and principles.
- `components/sections.tsx`: Reusable UI components for rendering profile data.
- `components/ag-01.tsx`: The interactive AI companion logic and UI.
- `app/globals.css`: Core design system and theme variables.
