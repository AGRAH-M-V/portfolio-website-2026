# Agrah M V - Portfolio

A minimal, dark-first personal portfolio built to showcase backend engineering experience, operating principles, and technical arsenal. 

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Lucide React

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Structure
- `data/profile.ts`: Centralized content for experience, projects, skills, and principles.
- `components/sections.tsx`: Reusable UI components for rendering profile data.
- `app/globals.css`: Core design system and theme variables.
