Refined “Living Engineer” Portfolio Evolution Plan
This updated plan refines the original direction to keep the portfolio minimal, premium, backend-focused, and Nothing-inspired without becoming overly gimmicky or roleplay-heavy.
Core Design Direction
Evolve the portfolio from: > “well-designed engineering resume”
into: > “minimal engineering workspace with personality”
The UI should communicate:
backend engineering maturity
reliability-first thinking
active learning
calm technical confidence
Avoid:
fake operating system aesthetics
exaggerated system simulation
overly theatrical engineering language
1. Data Model Updates (data/profile.ts)
Add Lightweight “Currently Exploring” Section
Introduce:
currentlyExploring: [  "AI workflow orchestration",  "Prompt evaluation systems",  "Backend observability patterns",  "gRPC service optimization"]
Purpose:
make the portfolio feel alive
show active curiosity
avoid static resume energy
Keep this section:
short
evolving
technical
personal
Do NOT use fake runtime states or mock system telemetry.

3. Layout & Card Refactor (components/sections.tsx)
Reduce Visual Dependence on Cards
Current UI relies slightly too heavily on bordered containers.
Refactor toward:
whitespace-driven structure
typography hierarchy
softer separation
BUT:
do NOT fully remove borders
do NOT make dense sections borderless
Instead:
reduce border opacity
increase padding
add more vertical breathing room
soften card visibility
Recommended direction:
border: rgba(0,0,0,0.08)
instead of strong visible containers.
4. Typography Hierarchy Improvements
Increase editorial feel through:
stronger section titles
cleaner spacing rhythm
slightly larger project titles
improved line height
more visual breathing room
Goal:
make the portfolio feel calmer
easier to scan
more premium
Typography should become the primary structural element instead of borders.
